2. Masuk ke admin

Admin tidak punya username dan password sendiri. Masuknya lewat akun Google.

  1. Buka Link Admin (simpan di bagian atas panduan ini).
  2. Kalau diminta, login dengan akun Google yang sudah didaftarkan sebagai admin.
  3. Pertama kali saja: Google meminta izin. Klik Lanjutan → Buka … (tidak aman) → Izinkan. Peringatan ini normal untuk aplikasi buatan sendiri.
  4. Halaman admin terbuka dengan tab Paket · Frame · Galeri · Instagram · Info Studio.
Tidak perlu daftar atau membuat password. Kalau email belum terdaftar, yang tampil adalah pesan Akses ditolak.
Menambah orang lain sebagai admin
  1. Buka Google Sheet → klik Bagikan → tambahkan email orang itu sebagai Editor.
  2. Buka editor Apps Script → Setelan project (ikon roda) → Properti skrip.
  3. Edit ADMIN_EMAILS: tambahkan emailnya, dipisah koma. Contoh: aksata@gmail.com,klien@gmail.com.
  4. Kalau tab Sheet dikunci (Lindungi sheet), tambahkan emailnya juga ke daftar yang boleh mengedit.
Browser saya login ke banyak akun Google

Google bisa membuka link dengan akun yang salah dan menampilkan "tidak dapat membuka file". Dua cara:

  • Buka jendela privat/Incognito, login hanya ke akun admin, lalu buka link admin.
  • Atau tambahkan nomor akun di link: ganti /macros/s/ menjadi /macros/u/1/s/ (coba 0, 1, 2, … sampai akun yang benar).
Bagaimana cara keluar?
Admin mengikuti login Google di browser. Untuk keluar, logout dari akun Google atau tutup jendela privat.

3. Tugas sehari-hari

Pilih apa yang mau kamu lakukan.

  1. Buka tab Paket.
  2. Klik Ubah pada paket yang dimaksud.
  3. Ubah isiannya, lalu klik Simpan.
  4. Klik Terbitkan ke situs.
Harga diisi angka saja, tanpa "Rp" dan tanpa titik. Contoh: 25000. Tampilan "25K" atau "25.000" diatur di isian Tampilan harga.

Satu baris pada Isi paket = satu poin centang di kartu paket.

  1. Buka tab Galeri (atau Frame) → klik + Tambah foto.
  2. Isi judul dan kategori, lalu pilih fotonya.
  3. Tunggu tulisan "Foto terunggah" sebelum menekan Simpan.
  4. Klik Simpan, lalu Terbitkan ke situs.

Mengganti foto yang sudah ada: klik Ubah pada item itu, pilih foto baru, tunggu "Foto terunggah", lalu Simpan.

Foto besar tidak masalah — otomatis dikecilkan sebelum diunggah. Foto yang tidak dipakai lagi ikut dihapus dari situs saat Terbitkan.

Sembunyikan sementara (data tetap tersimpan, tidak tampil di situs):

  1. Klik Pilih → centang item → Sembunyikan. Atau klik Ubah pada satu item dan matikan "Tampilkan di situs".
  2. Terbitkan.

Hapus: klik Hapus pada barisnya. Untuk banyak sekaligus: Pilih → centang → Hapus.

Hapus tidak bisa dibatalkan di admin. Kalau ragu, pilih Sembunyikan.
  1. Cari simbol ⠿ di kiri tiap baris.
  2. Tahan simbol itu lalu geser ke posisi baru. Di HP, menahan di bagian kosong baris juga bisa.
  3. Lepas. Muncul "Urutan tersimpan." lalu klik Terbitkan ke situs.

Urutan di admin = urutan di situs.

Buka tab Info Studio. Isinya: nama dan alamat, jam buka, kontak dan media sosial, kalimat pembuka, bagian yang ditampilkan, daftar pilihan cepat, dan judul untuk Google. Klik Simpan lalu Terbitkan.

Menggeser lokasi peta:

  1. Buka Google Maps, klik kanan titik lokasi studio, lalu klik angka koordinat paling atas untuk menyalinnya.
  2. Isikan angka pertama ke Latitude dan angka kedua ke Longitude. Pakai titik sebagai desimal.
  3. Kosongkan Link Google Maps agar tombolnya mengikuti koordinat.

5. Kalau ada masalah

Ketik kata kunci untuk mencari.

Muncul "Akses ditolak"
Email yang login belum terdaftar sebagai admin, atau kamu login dengan akun Google yang salah. Cek akun yang aktif, atau minta pemilik menambahkan emailmu (lihat bagian Masuk ke admin).
"Tidak dapat membuka file" / halaman Google Drive error
Browser memakai akun Google yang salah. Buka link admin di jendela privat setelah login ke akun admin, atau tambahkan /u/1/ (coba angka lain) pada link.
Terbitkan gagal: "GitHub 401"
Token GitHub salah atau dihapus. Buat token baru dan ganti nilai GITHUB_TOKEN (lihat Perawatan).
Terbitkan gagal: "GitHub 403" atau "404"
403: izin token belum Contents: Read and write. 404: nama repo di GITHUB_REPO keliru atau token tidak punya akses ke repo itu.
Saya sudah Terbitkan tapi situs belum berubah
Tunggu 2 menit lalu refresh keras. Kalau tetap sama, cek halaman Actions/Pages repo GitHub untuk melihat apakah build berjalan.
Foto tampil kotak "!" atau tidak muncul di admin
Foto belum selesai diunggah atau gagal dimuat. Hapus item itu dan unggah ulang, tunggu sampai muncul "Foto terunggah".
Harga tampil 0 atau aneh
Harga harus angka polos. Buka Ubah pada paket dan isi ulang, mis. 25000.
Lokasi peta salah
Periksa Latitude dan Longitude di Info Studio (pakai titik, bukan koma) dan kosongkan Link Google Maps. Simpan lalu Terbitkan.
Saya salah menghapus atau mengubah sesuatu
Di Google Sheet: File → Riwayat versi → Lihat riwayat versi, pilih versi sebelum kesalahan, lalu Pulihkan versi ini. Setelah itu buka admin, periksa, dan Terbitkan.
Perubahan saya tidak muncul di admin
Refresh halaman admin. Admin membaca langsung dari Sheet.

6. Perawatan

Token GitHub (izin untuk tombol Terbitkan)

Dipakai admin untuk menulis ke repo situs. Dibuat tanpa tanggal kedaluwarsa. Ganti kalau tokennya bocor atau tidak sengaja terhapus:

  1. Login ke GitHub akun Aksata → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Buat token baru: repo hanya aksatacerita.github.io, izin Contents: Read and write.
  3. Editor Apps Script → Setelan project → Properti skrip → ganti nilai GITHUB_TOKEN → Simpan.
  4. Hapus token lama di GitHub.
Cadangan data
Isi situs tersimpan di dua tempat: Google Sheet (ada Riwayat versi) dan repo GitHub (setiap Terbitkan = satu commit yang bisa ditelusuri). Cukup dua itu.
Batas layanan gratis
Pemakaian normal jauh di bawah batas. Pengunjung situs tidak memanggil Apps Script, hanya file statis di GitHub Pages, jadi kuota Google hanya terpakai saat admin bekerja.
Domain sendiri (misalnya .com atau .id)
Opsional. Beli domain atas nama pemilik usaha, lalu arahkan ke GitHub Pages di Settings → Pages → Custom domain pada repo situs.
