1. Cara kerjanya

Klik tiap kotak untuk tahu fungsinya, lalu mainkan simulasinya.

Klik salah satu kotak di atas.
Intinya: Simpan membuat situs langsung berubah. Terbitkan hanya membuat salinan cadangan permanen (dan memindahkan foto dari Drive ke GitHub). Jadi kalau GitHub sedang gangguan, situs tetap bisa diperbarui.
Apa yang dilakukan situs saat dibuka pengunjung?
  1. Menampilkan salinan cepat (data.json) dalam sekitar setengah detik.
  2. Lalu mengambil isi terbaru dari Sheet lewat pintu baca. Kalau berbeda, tampilan diperbarui otomatis (sekitar 2 detik).
  3. Kalau Google sedang bermasalah, pengunjung tetap melihat salinan cepat tadi — tidak pernah halaman kosong.

2. Masuk ke admin

Admin tidak punya username dan password sendiri. Masuknya lewat akun Google.

  1. Buka Link Admin (simpan di bagian atas panduan ini).
  2. Login dengan akun Google yang sudah didaftarkan sebagai admin.
  3. Pertama kali saja, Google meminta izin: Lanjutan → Buka … (tidak aman) → Izinkan. Peringatan ini normal untuk aplikasi buatan sendiri.
  4. Halaman admin terbuka dengan tab Paket · Frame · Galeri · Instagram · Info Studio.
Email yang belum terdaftar melihat pesan Akses ditolak. Admin yang terkunci itu disengaja: hanya orang di daftar yang bisa mengubah isi situs.
Menambah orang lain sebagai admin
  1. Google Sheet → Bagikan → tambahkan emailnya sebagai Editor.
  2. Editor Apps Script → Setelan project (ikon roda) → Properti skrip.
  3. Edit ADMIN_EMAILS, tambahkan emailnya dipisah koma: aksata@gmail.com,klien@gmail.com.
  4. Kalau tab Sheet dikunci, tambahkan juga ke daftar yang boleh mengedit.
Browser saya login ke banyak akun Google

Google bisa membuka link dengan akun yang salah ("tidak dapat membuka file"). Dua cara:

  • Pakai jendela privat, login hanya ke akun admin, lalu buka link admin.
  • Atau ganti /macros/s/ pada link menjadi /macros/u/1/s/ (coba 0, 1, 2, …).
Cara keluar
Admin mengikuti login Google di browser. Logout dari akun Google atau tutup jendela privat.

3. Tugas sehari-hari

Pilih apa yang mau kamu lakukan.

  1. Tab Paket → klik Ubah pada paket yang dimaksud.
  2. Ubah isiannya → Simpan.
  3. Selesai: situs ikut berubah dalam beberapa detik.
Harga diisi angka saja, tanpa "Rp" dan tanpa titik. Contoh: 25000. Tampilan "25K" atau "25.000" diatur di isian Tampilan harga.

Satu baris pada Isi paket = satu poin centang di kartu paket.

  1. Tab Galeri (atau Frame) → + Tambah foto.
  2. Isi judul dan kategori, lalu pilih fotonya.
  3. Tunggu tulisan "Foto terunggah" sebelum menekan Simpan.
  4. Simpan → foto langsung tampil.

Mengganti foto: Ubah pada item → pilih foto baru → tunggu "Foto terunggah" → Simpan.

Foto besar tidak masalah — otomatis dikecilkan sebelum diunggah. Sebelum Terbitkan, foto baru ditampilkan dari Drive; setelah Terbitkan, disalin ke GitHub agar tidak bergantung pada Drive.

Sembunyikan sementara (data tetap tersimpan):

  1. Pilih → centang item → Sembunyikan; atau Ubah → matikan "Tampilkan di situs".

Hapus: tombol Hapus di barisnya. Banyak sekaligus: Pilih → centang → Hapus.

Hapus tidak bisa dibatalkan di admin. Kalau ragu, pilih Sembunyikan.
  1. Cari simbol ⠿ di kiri tiap baris.
  2. Tahan lalu geser ke posisi baru (di HP, menahan di bagian kosong baris juga bisa).
  3. Lepas. Muncul "Urutan tersimpan." — urutan di situs ikut berubah.

Tab Info Studio: nama dan alamat, jam buka, kontak, kalimat pembuka, bagian yang ditampilkan, daftar pilihan cepat, judul untuk Google.

Menggeser lokasi peta:

  1. Google Maps → klik kanan titik studio → klik angka koordinat paling atas untuk menyalin.
  2. Angka pertama → Latitude, angka kedua → Longitude (pakai titik, bukan koma).
  3. Kosongkan Link Google Maps supaya tombolnya mengikuti koordinat.

5. Kalau ada masalah

Diagnosa cepat — pilih yang paling mirip:
"Akses ditolak" di admin
Email yang login belum terdaftar, atau kamu login dengan akun Google yang salah. Minta pemilik menambahkan emailmu (bagian Masuk ke admin).
Terbitkan gagal: "GitHub 401"
Token GitHub salah atau dihapus. Buat token baru dan ganti nilai GITHUB_TOKEN (bagian Perawatan).
Terbitkan gagal: "GitHub 403" atau "404"
403: izin token belum Contents: Read and write. 404: nama repo di GITHUB_REPO keliru atau token tidak punya akses ke repo itu.
Terbitkan berhasil tapi cadangan di GitHub belum muncul
GitHub kadang butuh 1–3 menit membangun, bahkan lebih saat GitHub sedang gangguan (cek githubstatus.com). Situs sendiri tidak terpengaruh karena membaca langsung dari Sheet.
Perubahan tidak muncul di admin
Refresh halaman admin. Admin membaca langsung dari Sheet.
Foto lama masih tampil setelah diganti
Refresh keras di browser: Cmd+Shift+R (Windows: Ctrl+Shift+R).
Situs terasa tidak berubah padahal sudah Simpan
Data dari Sheet disimpan sementara 5 menit di server, tapi dihapus otomatis setiap kamu menyimpan. Refresh halaman situs. Kalau tetap sama setelah 1 menit, kabari pengembang.

6. Perawatan & cadangan

Jadwal cadangan

Unduh salinan sendiri tiap 3 bulan. Catat tanggalnya di sini (tersimpan di browser ini).

  1. Google Sheet → File → Unduh → Microsoft Excel (.xlsx).
  2. GitHub repo situs → Code → Download ZIP.
  3. Simpan keduanya di tempat aman (Google Drive pribadi atau flashdisk).

Token GitHub (izin untuk tombol Terbitkan)

Dibuat tanpa tanggal kedaluwarsa. Ganti kalau bocor atau tidak sengaja terhapus:

  1. GitHub akun Aksata → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Token baru: repo hanya aksatacerita.github.io, izin Contents: Read and write.
  3. Editor Apps Script → Setelan project → Properti skrip → ganti nilai GITHUB_TOKEN → Simpan.
  4. Hapus token lama di GitHub.
Risiko jangka panjang — jujur
  • Akun terkunci / lupa password (Gmail atau GitHub): risiko terbesar. Cegah dengan 2FA, nomor HP & email pemulihan yang benar, dan kode cadangan.
  • Aturan layanan gratis berubah: tidak ada kontrak. Karena itu cadangan manual di atas penting.
  • Trafik sangat besar: kuota harian Google bisa habis; situs tetap tampil dari salinan statis.
  • Tidak ada yang memantau: pastikan ada satu orang yang dihubungi bila ada gangguan.
Domain sendiri (misalnya .com atau .id)
Opsional, atas nama pemilik usaha. Setelah dibeli, arahkan ke GitHub Pages di Settings → Pages → Custom domain pada repo situs. Untuk cetakan permanen (banner, kartu nama, QR) domain sendiri lebih aman daripada link pendek gratis.
Animasi di situs
Animasi hanya tampilan di browser pengunjung (tidak memengaruhi Sheet atau Apps Script). Pengunjung yang mengaktifkan "kurangi gerakan" di perangkatnya otomatis melihat situs tanpa animasi.

8. Untuk pengembang

Ringkasan teknis. Detail lengkap ada di README.md repo.

  index.html  css/  js/  img/  data.json  panduan.html
apps-script/     admin + API (Google Apps Script, via clasp)
  Code.gs  Admin.html  appsscript.json
Dua deployment Apps Script
NamaDijalankan sebagaiAksesFungsi
AdminPengguna yang membukaAkun Google + daftar ADMIN_EMAILSAdmin web app
Publik (hanya baca)PemilikSiapa saja?action=public → JSON isi situs (cache 5 menit, dihapus tiap menyimpan)

Alamat pintu baca ada di docs/js/config.js (API_URL). Kosongkan untuk mematikannya; situs kembali memakai data.json.

Perintah 
cd apps-script
npx @google/clasp push -f
npx @google/clasp create-version "catatan"
npx @google/clasp list-deployments
npx @google/clasp update-deployment <deploymentId> -V <versi> -d "Admin vN"
Setiap deployment terikat pada versi. Setelah mengubah Code.gs/Admin.html: push → create-version → update-deployment untuk kedua deployment bila perlu. Untuk deployment publik, manifest harus executeAs: USER_DEPLOYING dan access: ANYONE_ANONYMOUS saat versinya dibuat; kembalikan manifest admin setelahnya.
Pratinjau lokal 
cd docs && python3 -m http.server 8000
Catatan teknis
  • docs/.nojekyll menonaktifkan Jekyll → build Pages lebih cepat dan stabil.
  • Animasi: css/motion.css + js/motion.js (hanya opacity/translate/scale; hormati prefers-reduced-motion; tidak berkedip saat data diperbarui).
  • Render halaman ada di js/render.js; data diambil lewat js/main.js (data.json dulu, lalu Sheet).
  • Sheet memakai format teks biasa pada kolom teks agar locale Indonesia tidak merusak angka desimal (mis. koordinat).
  • Terbitkan = satu commit lewat Git Data API: docs/data.json + foto baru; foto yang tak terpakai dihapus.

Istilah

Simpan vs Terbitkan
Simpan: mengubah data di Sheet, situs ikut berubah dalam detik. Terbitkan: menyalin data & foto ke GitHub sebagai cadangan permanen.
Sheet
Google Spreadsheet tempat semua isi situs disimpan. Dikelola lewat admin; sebaiknya tidak diedit langsung.
Pintu baca (API publik)
Alamat khusus yang hanya mengeluarkan isi situs dalam bentuk data, tanpa login. Tidak bisa mengubah apa pun.
GitHub Pages
Layanan gratis GitHub yang menayangkan situs dari folder docs/ repo.
Token
Kunci rahasia yang memberi admin izin menulis ke repo GitHub. Jangan dibagikan.
2FA (verifikasi 2 langkah)
Lapisan keamanan tambahan: selain password, login butuh kode dari HP.
